# Zenin Ability — Minecraft 1.20.1 Fabric

Ability inspired by Naoya/Naobito-style frame trapping.

- Z toggles the ability.
- Left click a mob to trap it for 2 seconds.
- First hit: trap shatters immediately and that attack's base attribute damage is multiplied by 3.
- No hit for 2 seconds: trap shatters and the mob takes exactly 3 damage.
- Glass break sound + glass particles.
- HUD in the bottom-left.

Build: Java 17 + Gradle 8.5, `gradle build`.
